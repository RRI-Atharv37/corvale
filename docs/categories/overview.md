## Organize transactions with a flexible category system

The **Categories** page lets you classify income and expenses using a hierarchy of master categories and your own sub-categories. Every transaction links to a category so you can track spending and earning patterns.

Navigate to Categories from the sidebar or go to `/categories`.

## Master categories

Corvale ships with nine built-in master categories. You cannot edit or delete master categories, but you create sub-categories under them:

| Master | Typical use |
|--------|-------------|
| Food | Groceries, dining out |
| Transport | Gas, transit, rideshare |
| Entertainment | Streaming, events |
| Housing | Rent, utilities |
| Education | Tuition, books |
| Health | Medical, fitness |
| Shopping | Clothing, general retail |
| Income | Salary, freelance, gifts |
| Other | Anything else |

Each master has a default icon and color that sub-categories can inherit or override.

## What you can do

On the Categories page, you can:

- View all sub-categories grouped by master
- Create new sub-categories with custom names, icons, and colors
- Edit sub-category details
- Set one sub-category as your default
- Reorder sub-categories within a master group
- Archive sub-categories you no longer use
- Set up [auto-categorization rules](./categorization-rules.md) that assign a category automatically

## How categories connect to transactions

When you add or edit a transaction, the **Category picker** shows your sub-categories grouped by master. Pick the category that best describes the entry.

Archived categories do not appear in the picker but remain linked to existing transactions.

## Default category

You can mark one sub-category as your **default**. The picker may pre-select it when creating new transactions.

Only one active sub-category can be default at a time.
