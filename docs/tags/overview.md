## Label your transactions your way

**Tags** are short, colored labels you attach to transactions, recurring rules, and quick-add templates - useful for cutting across categories, like tracking everything related to a trip or a specific project.

Navigate to Tags from the sidebar or go to `/tags`.

## What you can do

On the Tags page, you can:

- Create tags with a name and color
- Rename a tag - the new name applies to every transaction that already used it
- Delete a tag you no longer need
- Turn any free-text tags already on your transactions into managed tags

## Tags vs categories

Categories classify a transaction's purpose (Food, Transport, Housing) and are required. Tags are optional and flexible - a single transaction can carry several tags alongside its one category. Use categories for budgeting and reports, and tags for cross-cutting labels that don't fit a category hierarchy.
