title: Using Tags
---

## Attach tags anywhere you see the tag picker

The tag picker appears on the transaction form, recurring rule form, categorization rule form, and quick-add template form. Type to filter existing tags, or type a new name and press Enter to create it on the spot - no need to visit the Tags page first.

## Tag chips

Once attached, a tag renders as a colored chip wherever transactions are listed. Each chip uses the tag's assigned color, so related items are easy to spot at a glance.

## Filtering by tag

On the **Transactions** page, use the tag filter row above the list to narrow results to transactions carrying one or more selected tags.

## Renaming and deleting

Renaming a tag on the Tags page updates every transaction that used the old name - you don't need to re-tag anything. Deleting a tag removes the tag itself; transactions that referenced it are not retroactively edited.
